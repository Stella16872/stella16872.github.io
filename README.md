# 项目索引

网址：<https://stella16872.github.io/>

所有 GitHub 项目的导航页，全部内容在 `index.html` 里。

**它会自己更新**：每次打开都实时调 GitHub 公开 API 读一遍仓库列表，
新项目推上去、开好 Pages，刷新这页就自动出现，不用改代码。
读不到 GitHub 时（断网、限流）退回到内置的快照，并在顶部标明。

给仓库填了 Description（仓库页右上角 About 旁边的齿轮），这里会跟着显示。

分三栏：

- **在线**：开了 GitHub Pages 的网页项目，点一下直接打开
- **本地程序**：要下载到电脑上运行的（工具箱、桌面宠物、后端程序），链接到 GitHub 仓库页
- **待处理**：空仓库、还没开 Pages 的

需要特殊处理的项目写在 `index.html` 里的 `OVERRIDE`：显示名、归到「本地程序」、
或者隐藏（比如旧仓库 `-`，里面只剩跳到新地址的页面）。
